# 01. プロジェクト概要

## プロジェクト名

TickStack

## プロジェクト概要

TickStackは、M5Stack Core2を活用した学習支援デバイスです。

ポモドーロタイマーやToDo管理は学習効率向上に有効ですが、多くの場合はスマートフォン上で利用されます。しかし、学習中にスマートフォンを開くことで通知やSNSに意識が移り、集中が妨げられることがあります。

そこで本プロジェクトでは、「設定はWeb画面、利用はM5Stack」という構成を採用し、学習中にスマートフォンを開かなくてもタイマーやタスクを確認できる仕組みを開発しました。

---

## システム概要

TickStackは以下の要素で構成されています。

- Web画面
  - タイマー設定
  - ToDo登録・編集
  - ユーザー管理

- Flask API
  - Web画面とM5Stackの仲介
  - データ取得・更新

- データベース
  - ユーザー情報
  - ToDo情報
  - タイマー設定

- M5Stack Core2
  - タイマー表示
  - ToDo表示
  - 時計表示
  - モード切替

---

## チーム体制

- 開発形態：大学のチーム開発プロジェクト
- チーム人数：5名

担当領域は大きく以下に分かれていました。

- M5Stack開発
- Web開発
- バックエンド開発
- データベース設計
- プロジェクト管理

個人情報保護のため、公開用ポートフォリオ版ではメンバー名や学籍番号は掲載していません。

---

## プロジェクトの目標

- スマートフォンを開く機会を減らす
- 学習に必要な情報をM5Stack上で確認できるようにする
- WebとM5StackをAPIで連携する
- ハードウェアとWebシステムを組み合わせたチーム開発を経験する
